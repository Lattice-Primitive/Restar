## 每个方向题目包含两部分

### 第一部分：技术深度题（1页以内）

- 给一个具体场景/代码/图纸
- 要求候选人展示思考过程——不是考对错
- 设计原则：题目不难到"做不出来"，但深到"能看出谁认真想了"

### 第二部分：职业认知题（必答，半页）

- "基于自学准备期的职业认知SOP，你对XX工程师这个职业了解多少？"
- "基于SOP的自学，你觉得这个方向适合你吗？为什么？"
- 考察：有没有按SOP做调研？对自己的职业方向有没有经过思考？
