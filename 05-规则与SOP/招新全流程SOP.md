## 全流程时间线（每年秋季学期）

| 时间节点 | 动作 | 负责人 | 产出物 |
|---------|------|--------|--------|
| 开学前 2 周 | 确认方案、更新题库、更新SOP、准备材料 | 负责人 | 全部材料 ready |
| 开学前 1 周 | 宣传启动：海报/推文/QQ群/口碑 | 运营组 | 宣传物料发布 |
| 开学第 1 周 | 宣讲会（90min） | 负责人 | 到场人数+报名表 |
| 第 1-2 周 | 自学准备期（报名者） | — | — |
| 第 2 周末 | 初试：笔试90min + MBTI 15min | 负责人+核心成员 | 答卷+MBTI结果 |
| 第 3 周初 | 评阅+复试通知+发放方向陈述题目 | 负责人 | 复试名单+题目 |
| 第 3 周中 | 方向陈述提交截止 | 候选人 | 方向陈述 |
| 第 3 周末 | 复试面试（每人20-30min） | 负责人+核心成员 | 面试记录 |
| 第 4 周初 | 复试结果通知+发放实战任务 | 负责人 | — |
| 第 4 周中 | 实战任务提交截止 | 候选人 | 首次月度产出 |
| 第 4 周末 | 预备期开始 | — | — |
| 第 5-8 周 | 预备期（1个月） | 负责人+核心成员 | 考核记录 |
| 第 8 周末 | 预备期结束→正式成员/淘汰 | 负责人 | 正式成员名单 |

## 各阶段详细检查清单

### 1. 宣传阶段
- [ ] 确认宣传渠道（海报张贴位置 / QQ群号 / 公众号）
- [ ] 制作/更新宣传物料
- [ ] 确定宣讲会时间地点并发布
- [ ] 建立招新咨询群

### 2. 宣讲会
- [ ] 准备好PPT
- [ ] 打印宣传手册 20 份
- [ ] 准备好题库链接+SOP电子版（发群里）
- [ ] 准备好报名表（纸质/电子）
- [ ] 提前到场布置

### 3. 自学准备期
- [ ] 群内发题库+SOP
- [ ] 群内发初试时间地点通知（提前3天）
- [ ] 准备初试试卷（从题库改数据出题）
- [ ] 准备MBTI测试链接

### 4. 初试
- [ ] 打印试卷（多印5份备用）
- [ ] 确认MBTI测试平台可用
- [ ] 安排监考（你+1个核心成员）
- [ ] 考后2-3天内完成评阅

### 5. 复试
- [ ] 评阅答卷+MBTI交叉，确定暂定方向
- [ ] 发放复试通知+方向陈述题目
- [ ] 收到方向陈述后，审阅+准备追问
- [ ] 安排面试时间表（每人20-30min，留间隔）
- [ ] 面试当天：使用复试评估表记录

### 6. 实战任务
- [ ] 复试通过后发放实战任务
- [ ] 3天后检查提交情况
- [ ] 未提交的→不进预备期

### 7. 预备期
- [ ] 预备期开始说明会（10min）
- [ ] 安排每周分享排期
- [ ] 月末第一次月度考核
- [ ] 预备期结束：定组+发放正式成员通知

## 每年需要更新的部分

| 内容 | 更新频率 |
|------|---------|
| 题库题目 | 每年更新（改数据+换题） |
| 方向陈述题目 | 每年更新 |
| 宣传手册 | 每年更新（新增成果/学长去向） |
| 第一课PPT | 每年更新（新增案例/数据） |
| 时间线具体日期 | 每年根据校历调整 |
